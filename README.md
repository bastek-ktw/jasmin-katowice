# Salon Kosmetyczny Jasmin | Katowice

Strona internetowa Salonu Kosmetycznego Jasmin w Katowicach (podologia, manicure, pielęgnacja twarzy i ciała).

## Zawartość repozytorium
- `index.html` – główna strona salonu (HTML5, CSS3, JS)
- `favicon.ico`, `favicon.png` – ikony strony
- `images/` – zdjęcia gabinetu, zespołu, portfolio zabiegów oraz logotyp
